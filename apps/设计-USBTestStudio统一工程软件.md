### 0.5 全局反馈体系

1. **通知**：右下角 toast（info 3s 自消 / warn 5s / error 常驻手动关），全部留存通知中心（状态栏入口，红点计数，清空按钮）。
2. **耗时规则**：>200ms 操作必须出进度（可取消）；>2s 转后台任务，状态栏齿轮转动指示，完成 toast。
3. **破坏性操作**：统一危险对话框流（说明后果+影响范围+输入确认词）。适用清单：msc_write_verify、全盘填充、批量禁用设备、DFU 擦除。
4. **空态三件套**（每个面板必须实现）：一句状态文案 + 一个主行动按钮 + 一个"查看帮助"链接。禁止白板。
5. **错误四件套**：发生了什么 / 为什么 / **下一步动作按钮**（占位明确，如"跳去关闭会话"）/ 诊断信息复制按钮。

### 2.3 产线大屏模式（F11，operator 视图）

```
┌──────────────────────────────────────────────────┐
│ STN-01 · lab1-HID 复合设备产测      SN: SN123456   │  顶栏 60px
│                                                  │
│                ████████████████                  │
│                ██  PASS  3/3  ██   ← 色块占屏 70%  │
│                ██  4.3s       ██      运行中=蓝+进度环│
│                ████████████████       FAIL=红+失败号│
│                                                  │
│        [⏹ 停止(ESC)]     下一步: 扫下一台 SN        │
└──────────────────────────────────────────────────┘
```

规则：扫码即自动启动（SN 框常驻聚焦）；PASS=短促滴一声+绿屏 1.5s →回"扫下一台"待机灰屏；FAIL=长鸣两声+红屏**常驻**直到按 [确认] 或 ESC；运行中=进度环+当前步骤名；设备占用/拔出=红屏+原因+解决按钮（如 [跳去关闭会话]，仅工程师模式可见）；右上角小字时钟与今日计数（今日 N 台 · 通过 N）。声光开关在设置中心。

## 8. usts_runner.exe（无 UI，CLI）

`usts_runner.exe --plan <path> --dut-sn <SN> --station <STN> [--mock] [--pipe <name>]`；管道上行消息 JSON-lines：`plan_loaded / step_start / step_result / run_done(verdict, crashed, report_path)`；退出码 0/1/2(中止)/3(计划错误)——**与现行契约一致**；无 `--pipe` 时 stdout 打印同构文本（MES 直接用）。

## 9. 非功能验收红线（V1.0 DoD）

1. 日志/会话视图 10 万行虚拟化滚动无感知卡顿（<16ms/帧）；
2. 目录 500 设备全量刷新 <1s（异步，UI 不冻结）；
3. 布局/DPI/设置跨启动记忆，双显示器拖动不糊不裁切；
4. runner 崩溃不影响 GUI 存活，可一键重跑；
5. 任一功能 DLL 缺失→对应入口灰+安装指引，主程序其余功能不受影响；
6. 全部破坏性操作走危险确认流；ESC 全局可用；
7. 每面板空态/错误态四件套齐备（§0.5）。

## 10. 面板注册表（框架-面板契约）
