# EP-4 · 工程师通信控制台 真机验收清单

> 对应设计：[设计-工程师通信控制台.md](设计-工程师通信控制台.md) §五切片表。
> 代码侧 S1~S5 已全量离线自测（405 例）+ MSVC 五靶零告警；本清单为**整片真机验收**，
> 需真机/工装，自主会话不可执行——由人工按表逐项过，结果记入文末记录表。
> 启动：`USBTestStudio.exe --console`（不带参数为产测模式，与本验收无关）。

## 准备

- [ ] Windows 10 1607+（PerMonitorV2）；管理员权限一个终端（MSC PhysicalDrive 打开可能需要）
- [ ] 器材：任意 USB 键盘或鼠标（HID）；USB 串口线/开发板（CDC 或 CP210x 等，知悉 COM 号与波特率）；
      WinUSB 设备（Lab 固件或 Zadig 绑 WinUSB 的任意设备）；U 盘一只（MSC，容量 ≤2TB）
- [ ] 离线基线先行：`ctest` 或逐个运行 4 个 `*_selftest.exe`（channel 163 / discovery 62 / session 95 / parser 85）全绿

## A · S1+S2 设备发现（验收标准：输入关键词 3 秒内定位目标设备）

| # | 步骤 | 预期 |
|---|---|---|
| A1 | `--console` 启动，接入全部四类设备后 F5 | 表内出现 HID/串口/usb/msc 四类行，名称/VID:PID/协议列非空 |
| A2 | 搜索框输入串口设备 VID 或名称片段 | 列表实时收敛（键入即过滤，无卡顿）；清空恢复全表 |
| A3 | 输入多关键词（空格分隔，如 `2341 key`） | AND 语义收敛 |
| A4 | 只勾 MSC 复选框 | 仅 msc 行保留；各复选框独立生效 |
| A5 | 拔插一次设备再 F5 | 行消失/重现，无崩溃无残留 |
| A6 | 高 DPI 屏（150%/200%）拖动窗口与跨屏 | 布局随 DPI 缩放，无截断（已知限制：ListView 列宽按 96dpi，README §7.7） |

## B · S3 会话收发（HID 与串口各开一会话）

| # | 步骤 | 预期 |
|---|---|---|
| B1 | 双击串口设备行 | 新标签页打开，状态行显示 COMx@波特率 |
| B2 | 发送框输入 `01 02 03`（纯 Hex）回车 | 识别为 Hex；OUT 行显示 `01 02 03` |
| B3 | 输入 `hello 世界` | 自动切 ASCII；接收端 UTF-8 中文正确 |
| B4 | 奇数位 `ABC` | 补前导 0 → `0A BC` 发出 |
| B5 | 勾周期 500ms | 按 500ms 连续 OUT 行；改 100ms 即改即生效；取消即停 |
| B6 | ↑/↓ 历史回选 | 50 条内回选；↑ 再无更早时草稿不丢 |
| B7 | 设备回发数据 | IN 行带时间戳滚动；暂停后仍后台收、恢复补齐不丢帧；清屏不清统计 |
| B8 | Hex↔ASCII、相对↔绝对切换 | 全量重渲染一致 |
| B9 | 双击 HID 设备行 | 会话打开；敲键盘/动鼠标产生 IN 帧 |

## C · S4 解析面板（HID 键盘/鼠标）

| # | 步骤 | 预期 |
|---|---|---|
| C1 | 键盘会话按住 Shift+A | 解析视图显示修饰键 Shift↓ 与 KeyA↓；松开消失 |
| C2 | 鼠标会话移动+左键 | 按钮 B0 与 X/Y 位移符号正确（双向均有） |
| C3 | 原始↔解析切换 | 同一行两视图正文不同、时间戳/方向一致；无解析器时开关置灰 |
| C4 | 消费页设备（遥控/多媒体键） | B0~B8/CD/E2/E9/EA 出名称（有则测，无则记 N/A） |

## D · S5 MSC / WinUSB（验收标准：对 U 盘读扇区）

| # | 步骤 | 预期 |
|---|---|---|
| D1 | 勾 MSC，F5，搜索框输 `PhysicalDrive` | U 盘一行，显示容量/扇区大小/INQUIRY 身份 |
| D2 | 双击 msc 行开会话，发送框发 READ_CAPACITY CDB：`25 00 00 00 00 00 00 00 00 00` | IN 帧 8 字节，解析视图/Hex 均可看；容量与 D1 行一致 |
| D3 | 发 READ(10)（LBA0 一块，块数大端 [7..8]）：`28 00 00 00 00 00 00 00 01 00` | IN 帧一块数据；首扇区含 MBR/分区表可肉眼判读 |
| D4 | 发写命令 `2A 00 …`（任一 WRITE(10)） | 拒收，err 提示"MSC 会话只读"，**盘上无写入**（可用读校验工具复核） |
| D5 | 发 TEST UNIT READY：`00 00 00 00 00 00` | 命令完成（无数据帧或 SENSE 帧，正常盘应为无帧） |
| D6 | WinUSB 设备双击开会话 | 打开成功显示 VID:PID 与 IN/OUT 管道号；打不开时 err 区分"未绑 WinUSB 驱动" |
| D7 | 发一帧 OUT；设备回发一帧 | OUT/IN 行成对出现 |
| D8 | 固件停收 OUT（或拔一半）再连发 | 3s 写超时报"设备未接收 OUT 传输"，**UI 不冻结**，可继续操作（evolve #71 防线） |
| D9 | 发送途中拔设备 | 会话报错/读线程退出，控制台不崩溃 |
