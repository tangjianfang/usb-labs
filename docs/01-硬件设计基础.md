# 01 · USB 硬件设计基础（全实验室通用）

> 所有 USB 设备硬件设计的公共部分。按"检查项"组织——G1 原理图评审时逐条打勾。

## 1. 差分对（D+/D-）

| 检查项 | 要求 |
|---|---|
| 阻抗 | 90 Ω ±15% 差分阻抗；4 层板优先（内层参考平面完整） |
| 等长 | D+/D- 长度差 < 1.5 mm（FS/HS 足够；HS 高速建议 <0.5 mm） |
| 参考地 | 全程有完整地平面参考，禁止跨分割 |
| 器件 | 串联/换层 所需的过孔数量最少化；ESD 器件结电容 ≤1 pF（HS 场景） |
| 走线长度 | 机内走线尽量 ≤10 cm（更长需仿真） |

规范依据见知识库 [物理层与电气特性](https://github.com/tangjianfang/USBTree/blob/main/10-树干-USB核心/03-物理层与电气特性.md)。

## 2. ESD 与浪涌

- 位置：ESD 阵列**紧贴连接器**放置（先 ESD 后走线进入板内）；
- 选型：低结电容（≤1 pF）双向 TVS 阵列（如 USBLC6-2SC6 类封装），VBUS 用功率 TVS/OVP；
- 等级目标：IEC 61000-4-2 接触 ±4 kV / 空气 ±8 kV（DVT 实测）；
- 教训：廉价 USB 设备返修的最大来源之一就是 ESD 省料或位置错误。

## 3. 时钟

- FS/HS 对时钟精度要求 ±0.25%（FS 设备）——**内部 RC 振荡器通常不达标**，必须晶振或合格的内嵌 PLL 方案；
- 晶振布局：紧靠 MCU、走线短、包地、负载电容按晶振 CL 计算；
- 32.768 kHz（BLE 类）：精度直接影响睡眠功耗（见 Lab6）。

## 4. 电源

| 项 | 要点 |
|---|---|
| VBUS 输入 | 5V 输入经 OVP/TVS；总线供电设备注意 inrush（浪涌）限制（规范要求） |
| 去耦 | 连接器 VBUS 引脚就近大电容+各 IC 100nF |
| LDO/DCDC | 按峰值电流（无线设备 RF 发射峰值）选型并留裕量 |
| 挂起电流 | 总线供电设备挂起态 ≤2.5 mA（USB2.0）——硬件漏电流要逐路核算 |

## 5. 连接器

- 选正规渠道（假 Type-C/A 公母端子是行业顽疾）：接触电阻、插拔寿命（Type-A ~1500 次、Type-C 10k 次）；
- 固定方式：SMT + 定位柱/铆接，防焊接应力；
- 屏蔽壳接地方式（360° 搭接 vs 引脚接地）按 EMC 目标决定。

## 6. PCB 叠层建议

| 层数 | 适用 | 叠层建议 |
|---|---|---|
| 2 层 | LS/FS 简单设备 | 顶层信号+地灌铜，底线：USB 差分两侧包地 |
| 4 层 | HS/量产主流 | TOP-GND(SIG)-PWR-BOTTOM，差分走 L1 参考整层 GND |
| 6 层+ | HS 带无线/多电源 | 增加电源平面，RF 区域独立处理（Lab6） |

## 7. 与协议的对照

硬件决定"能不能跑"，协议决定"跑得对不对"——两者用**抓包**闭环：EVT 阶段的枚举抓包比对清单见 [02-抓包分析实战](02-抓包分析实战.md)。
