# 03 · 商业实战总纲

> 把"能用"变成"能卖"的那部分工程。以下为公开行业共识的整理，具体数字以你的供应链与目标市场为准。

## 1. 目标成本倒推

```
零售价 ≈ BOM × 3~5（消费电子经验区间，渠道/品牌权重不同）
→ 先锁零售价与毛利，倒推 BOM 上限
→ BOM 里给认证、治具、返修预留 ≥10% 意识（不进 BOM 但进账本）
```

主控价格量级（USD，随行情浮动）：CH552 ≈ 0.2~0.4 / CH32V203 ≈ 0.3~0.5 / RP2040 ≈ 0.3~0.7 / STM32F103 ≈ 0.8~1.5 / STM32H7 ≈ 5~10 / nRF52840 ≈ 2~4。

## 2. 认证矩阵（按目标市场勾选）

| 认证 | 市场 | 强制性 | 与 USB 相关项 |
|---|---|---|---|
| CE-EMC/RED | 欧盟 | 强制 | 辐射/传导/ESD/RF（RED 含无线） |
| UKCA | 英国 | 强制 | 同 CE 范围 |
| FCC Part 15B | 美国 | 强制 | 无意辐射；含无线则 15C |
| **SRRC** | 中国 | 无线设备强制 | 2.4G 设备型号核准 |
| RoHS/REACH | 欧盟 | 强制 | 有害物质 |
| CCC | 中国 | 电源类强制 | 充电器/电源适配器 |
| USB-IF 认证 | 自愿 | 建议零售品牌做 | Logo 使用权、互操作背书（成本量级数千~万 USD，以官方为准） |
| 外设生态认证 | 自愿 | 视客户 | Zoom/Teams 认证（会议设备）、MFi（苹果生态） |

## 3. 供应链实战

- **主控二供**：Pin-to-Pin 备选（如 STM32F103 ↔ GD32/CH32F103 类兼容）——缺货周期 30~50 周的年份不是传说；
- **连接器防假**：USB 端子假货重灾区（接触电阻大、寿命短），走代理或原厂直供；
- **MOQ 与打样**：手板阶段用立创/JLC 类快板+元件贴装（几百元级打样），量产再切正规板厂；
- **存储颗粒**：U 盘黑片/白片市场水深——用 f3 鉴伪工具在来料检验里加一道（见 Lab3）。

## 4. 固件升级与售后

- 出货前锁死升级通道设计（bootloader+双分区，参考 Lab2 DFU）；
- 序列号写入与查询（售后定位批次）；VID/PID 规划（买自己的 VID 约 2000 USD/年量级，以 USB-IF 为准，小批量可先共用方案商 VID 但失去品牌独立性）；
- 客诉分类统计：枚举类/功能类/兼容类——分别对应硬件/固件/生态问题（[70-排查手册](https://github.com/tangjianfang/USBTree/blob/main/70-枝干-调试测试与安全/02-枚举失败排查手册.md)）。

## 5. 风险清单（公开资料常见坑汇总）

1. ESD 省料 → 旺季客诉高峰（静电季节）；
2. 晶振用劣质件 → 高温/低温枚举失败；
3. Type-C 只接了 D+/D- 没处理 CC → 插 C-to-C 线不工作；
4. 固件无版本号可查 → 售后无法定位；
5. 认证只做了 CE 忘了目的国无线核准 → 海关扣货。
