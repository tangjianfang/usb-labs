# 00 · 全栈方法论：从想法到量产的六阶段

> 本文件定义 USB-Labs 所有实验室共用的开发节奏。商业硬件项目与软件项目最大的不同：**返工成本随阶段指数上升**——软件改一行是零成本，PCB 改一版是 2~6 周+开模费，量产后改硬件是召回。

## 阶段门（Stage Gate）模型

| 阶段 | 目标 | 关键产出 | 退出标准（Gate） | 典型耗时 |
|---|---|---|---|---|
| **G0 选型** | 技术路线+主控+BOM 拓扑冻结 | 选型对比表、单价的量级区间、风险评估 | 样片可购、生态可支持全部协议需求、单价满足目标成本 | 1~2 周 |
| **G1 原理图** | 电路设计冻结 | 原理图评审记录、BOM V1.0 | 评审通过（电源树/USB 差分/ESD/晶振四项必查，见 [01-硬件设计基础](01-硬件设计基础.md)） | 1 周 |
| **EVT**（工程验证） | 功能打通 | 手板 5~10 片、固件 V0.x | 全功能 demo + 枚举零报错 + 基础抓包比对（见 [02-抓包分析实战](02-抓包分析实战.md)） | 4~8 周（含打板贴片） |
| **DVT**（设计验证） | 可靠性+合规 | 环境试验报告、预认证测试 | 高低温/ESD 接触放电 ±4kV 通过、EMC 预扫通过、连续老化 72h 无故障 | 4~6 周 |
| **PVT**（生产验证） | 产线良率 | 量产固件+治具+测试工装 | 试产良率 ≥ 目标值（消费级常见 ≥95%），SOP 作业指导书定稿 | 2~4 周 |
| **MP**（量产） | 交付 | 出货 | — | 持续 |

## 各阶段的 USB 专项动作

| 阶段 | USB 专项 |
|---|---|
| G0 | 主控 USB IP 能力核对（FS/HS、端点数、是否有 PHY）、协议栈选型（TinyUSB/厂商 SDK）、目标 OS 兼容清单 |
| G1 | D+/D- 差分 90Ω、共模抑制、ESD 器件选型（低结电容）、VBUS 处理（OVP？）、晶振精度（±0.25%@FS） |
| EVT | **枚举抓包全流程比对**（对照 captures/00）、全传输类型压测、挂起/恢复、跨平台兼容矩阵（Win/macOS/Linux/Android） |
| DVT | EMC 辐射/传导预扫、ESD 空气 ±8kV/接触 ±4kV、插拔寿命（Type-C 10k 次）、温漂下的时钟偏差复测 |
| PVT | 在线测试治具（VBUS 电压/电流、枚举自动化脚本）、烧录校验、外观检验标准 |
| MP | 客退分析流程、固件 OTA/DFU 升级通道（见 Lab2） |

## 成本意识贯穿全程

- **BOM 单价区间**写法：所有实验室的 BOM 都标"量级区间（USD）+ 随行情浮动"，采购以实时报价为准；
- 目标成本倒推法：零售价 ≈ BOM × 3~5（消费电子经验区间），先定零售价再倒推 BOM 上限；
- 二供（second source）：主控与关键料（ESD/连接器）必须有 Pin-to-Pin 备选，否则缺货=停线。

## 固件工程

- 版本策略：bootloader + app 双分区（升级可回滚，参考 Lab2 DFU）；
- 构建可复现：锁定 SDK 版本与工具链版本，CI 编译（本仓库后续可加）；
- 现场诊断：所有实验室的固件都保留一条"日志出口"（CDC 串口或 LED 闪烁码）。
