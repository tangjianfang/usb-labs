# USB DevStudio MS3/MS4/MS5 实施计划（合并）

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (recommended) / superpowers:executing-plans。

**Goal:** 完成工作站六台收口：MS3 测试台（Test Explorer/双后端/Pipeline/执行视图/报告中心）、MS4 追踪台（时间线/过滤 DSL/统计/diff）、MS5 核心切片（W1 诊断三件套/插件 ABI/脚本记录回放/知识服务/MES 模板/权限模型）。

**范围诚实账（写明防蔓延）：** ①计划文件=JSON 形状（三端契约同名同义；YAML 解析归 MS5+ 滚动）；②双后端=**虚拟(vd_core)+mock**——真机后端复用现有 TestEngine（--legacy 路径），执行视图 GUI 统一归后续滚动；③EP-4 控制台完整面板化归 MS5+，MS3 落"调试视角→打开控制台"命令；④MS5 为滚动里程碑，本计划落其核心切片，长尾（i18n/更新/无障碍/MSC 基准/UAC 扫频…）保持 ROADMAP 排队口径；⑤pcapng 解析归滚动（MS4 落 .uststrace 自有格式+USBPcap 外联占位）。

**Targets:** 第九/十靶并入门内——`te_selftest.exe`（MS3）、`trace_selftest.exe`（MS4）；MS5 切片并入 te 靶。Global Constraints 沿 MS0~MS2 全文。

## MS3 · 测试台（W5）+ 产线归位（W6）

### T1 计划模型 te_model.h
`PlanStep{name,type,params}`+`PlanModel{steps}`+`plan_from_json/to_json`（契约同 Python 字段名：type/name/limits…）+`scan_plans(dir)`（*.json 计划索引）。
测试：roundtrip/扫描/坏文件跳过。

### T2 双后端执行 te_runner.h
`Backend{Mock,Virtual}`；`StepOutcome{name,pass,measured,note}`；`run_plan(PlanModel, VirtualDevice*|nullptr, backend)`——Virtual 后端：enumerate 步=驱动枚举断言状态 Configured；mock=确定性通过；limits 判定（min_hz 等→mock 值）。
测试：mock 全 PASS/虚拟后端枚举步对 vd 设备真跑/失败步不中断/verdict。

### T3 Pipeline pipeline.h
`.ustsflow` 节点链（run_plan/delay/assert_report/external）+ `PipelineRunner`（顺序执行+失败策略 abort/continue）+ roundtrip。
测试：三节点链执行序/delay 拍/失败 abort/continue 分支/roundtrip。

### T4 执行视图+报告中心面板 te_editor.h
薄壳：w5.runner（步骤表+verdict 横幅）+ w6.report_list（reports\*.json 扫描列表+双击详情文本）。VM 测试+隐藏烟测（跑 mock 计划→步骤行数/verdict）。

### T5 收口
v0.13.0/CI te 靶/菜单（运行▾=当前计划 mock|虚拟）/ROADMAP MS3 勾/全靶+smoke/推送。

## MS4 · 追踪台（W4）

### T6 时间线模型 trace_model.h
`TraceRow{ts_ms,source,dir,summary,hex,mark}`+追加+视口+`from_vd_events(VirtualDevice)`（vd 事件→时间线）。
测试：追加/视口裁剪/vd 事件转换字段级。

### T7 过滤 DSL trace_dsl.h
子集文法：`field op value`（==/!=/>/<）+`&&`/`||`/`!`+括号；字段域 `usb.dir/usb.ep/len/src/summary~`（contains）；解析→AST→`matches(row)`；语法错→err 位置。
测试：语法树/匹配正负/优先级/括号/非法输入 err。

### T8 统计+diff trace_stats.h
带宽时间序列（ms 桶）/方向占比/NAK 率/源占比；`diff_traces(a,b)`（按序对齐,差异行列表）。
测试：统计数值断言/diff 增删改行。

### T9 W4 面板 trace_editor.h + 收口
薄壳：过滤输入+即时过滤列表+统计静态卡+diff 入口。v0.14.0/CI trace 靶/ROADMAP MS4 勾/全靶+smoke/推送。

## MS5 · 核心切片

### T10 W1 诊断 w1_diag.h
①能力档案 `capability_json(DeviceInfo)`（vid/pid/类/端点/驱动→JSON 清单）②ghost 扫描数据层（设备列表+present 标志→ghost 列表）③WinUSB 绑定向导三步 VM（选设备→兼容 ID 生成→绑定校验状态机）。
测试：档案字段/ghost 判定/向导步流转与校验文案。

### T11 插件 ABI plugin_abi.h + 脚本记录 script_console.h
plugin.json manifest 模型（四扩展点 panel/step/parser/device-template）+`PluginRegistry::load_manifest(json)`；脚本：`CommandRecorder`（记录命令 id 序列→jsonl 回放→逐条 invoke）。
测试：manifest 解析/非法扩展点拒绝/记录回放往返/回放计数。

### T12 知识服务+MES 模板+权限 kb_service.h
`kb_lookup(field_or_rule)`→条款引用（首批：25 Linter 规则+描述符字段表，kb.json 由 rules 数据生成）；`mes_command(report_path, station, sn, exit_code)`→PowerShell/curl 上报命令文本；`RolePolicy`（operator/engineer/admin→命令前缀白名单）。
测试：kb 查询命中/MES 文本形状/角色判定正负。

### T13 MS5 收口
v0.15.0/CI/ROADMAP（MS5 核心切片 ☑，长尾滚动清单明示）/全九靶+smoke/推送。
