## 1. 配对/重连体验设计

体验标准：**用户从"按下配对键"到"能打字"≤ 10 秒；日常开盖/开机重连 ≤ 1 秒**。

| 环节 | 设计要点 | 协议支撑 |
|---|---|---|
| 进入配对 | 短按配对键 → 清**当前通道**绑定（仅当长按才清；短按不清是防误触售后），以 20–30ms 快速间隔广播 ≥ 30s | GAP 可连接广播 |
| 配对模式 | Just Works（NoInputNoOutput）即可商用；对安全敏感客户再提供 Passkey 入口。**不要默认 MITM**——键盘没有显示，Passkey 流程会吓退普通用户 | SMP IO 能力协商 |
| 白名单 | 配对成功即入白名单（bond 落 Flash/settings）；广播过滤只接受白名单主机 | 加速重连 + 防陌生设备骚扰连接 |
| 重连 | 首选**定向广播**（ADV_DIRECT_IND 指向已绑主机），秒连；持续数秒未果回落慢速非定向（1–2s 间隔）省电 | 见 [capture/BLE连接帧分析.md](capture/BLE连接帧分析.md) §7 |
| 多主机冲突 | 一台键盘绑 3 台设备，切换通道时主动断开旧连接再向新主机定向广播，避免"两头抢" | GAP |

售后经验（公开资料共识）："键盘连不上"类工单的第一处置手段是**清除绑定重新配对**——产品必须把这个动作做得傻瓜化（长按组合键），并在说明书/包装印上步骤。 dongle 通道同理：拔插 dongle 触发再同步，不应要求重配对。

## 2. 延迟优化：7.5ms 的功耗代价与实测

### 2.1 理论账

- BLE 连接间隔下限 **7.5ms**（规范值）。间隔越短，报告延迟越低，但射频唤醒次数越多。
- 量级对比（每秒连接事件数，无 slave latency）：7.5ms≈133 次/s；15ms≈67；30ms≈33。**打字场景键盘 99% 时间无键按下**，稳态平均电流几乎由"空闲时的连接事件"决定 → 7.5ms 空闲功耗可达 30ms 的数倍（精确倍数取决于每事件时长与启动电流，用 PPK2 实测自己的固件）。
- 商业折中（共识做法）：
  - 打字时临时切短间隔（如 7.5–15ms），空闲数秒后经 L2CAP 参数更新切回长间隔（如 75–150ms + slave latency）；
  - "游戏模式/性能模式"作为卖点开关，明示续航代价；
  - 配合 slave latency（如 latency=4）让空闲期实际唤醒次数减为 1/5。
- 对比锚点：USB dongle 全速 HID 为 1ms 轮询，是"电竞级"宣传口径的物理来源；BLE 再怎么优化也追不平 1ms，这是产品定义时要诚实面对的差距。

### 2.2 实测方法（可复现）

1. **功耗侧**：PPK2（数百元人民币量级）串入供电，采样 µA 级电流，观察连接事件脉冲间隔与宽度，验证参数更新真的发生了。
2. **延迟侧**：抓包法——nRF Sniffer 时间戳（µs 级）测"按键 → HID Notification 空口时刻"；配合录音/高速摄像对齐物理按键动作（社区通行土办法），得到端到端延迟分解：扫描去抖 + 连接间隔等待 + 空口传输 + 主机处理。
3. 两套数据都留档进 DVT 报告，这就是未来"电竞款/办公款"双 SKU 的证据链。

## 3. 多设备切换（通道按钮）

通行交互（罗技/雷柏类产品的共识形态）：

- `Fn+1/2/3` 或独立通道键循环：通道 1 = dongle（私有 2.4G），通道 2/3 = 蓝牙直连。
- 切换动作 = "断开当前连接 → 向目标主机定向广播/触发 dongle 链路再同步"，目标 ≤ 1 秒可用。
- LED 闪 N 次指示通道号；切换失败要有兜底（60s 后自动跳回上一可用通道）。
- 实现核心：**三份独立绑定槽位**（各自白名单/LTK/CCCD 缓存），配置结构体按通道索引；存储区按槽位划分，避免清一个槽毁掉全部绑定。
- 测试矩阵（DVT 必测）：三台主机同时在线时反复切换 100 次，无掉线、无串扰（A 主机收到 B 的按键=串扰，量产级事故）。

## 4. RF 认证（FCC / CE / SRRC / MIC / KC）

无线键鼠是**无线电发射设备**，出货目的地决定认证清单。以下为共识级概览，**费用与细则以现行法规和检测机构报价为准**：

| 目的地 | 认证 | 要点 |
|---|---|---|
| 中国大陆 | **SRRC 型号核准（无线电发射设备型号核准）** | **强制性**：2.4GHz 键鼠在国内销售必须取得型号核准、标注 CMIIT ID；属《无线电发射设备型号核准目录》内设备。受理与测试由国家无线电监测中心检测中心体系承担（官网 https://www.srrctest.org.cn/ ）。周期与费用为数万元人民币量级（随产品与机构浮动）。注意：SRRC 与 CCC 相互独立，无线产品通常两者都要 |
| 美国 | FCC（Part 15，2.4GHz 数字调制/跳频条款） | 需 FCC ID；若用已获**模块认证**的射频模组可简化（列名/引用），这是选模块方案的隐性红利 |
| 欧盟 | CE / RED 2014/53/EU | 频谱 EN 300 328 + EMC EN 301 489 + 安全 EN 62368-1 + RF 人体暴露相关标准；RED 要求 DoC 与技术文档留存 |
| 日本/韩国 | MIC 技适 / KC | 有计划出货再补，量小可先用认证模块 |

- **整机认证 vs 模块认证**：裸片（nRF52840 贴片）通常走整机认证；认证模块（很多厂商供 nRF52 级认证模块）可引用其 FCC/CE 结果，缩短周期——BOM 贵一点，认证省一截，G0 阶段就要算这笔账。
- 认证前自摸底：蓝牙 **DTM（Direct Test Mode）传导测试**（屏蔽箱 + 频谱仪，或 nRF Connect for Desktop 的 DTM 工具）验证发射功率/频偏/杂散，过了再去实验室，避免重测费。

## 5. 量产烧录与校准

- **烧录**：SWD（TagConnect/顶针夹具）一拖多编程器或产线烧录器；镜像 = 应用 + 设置分区模板。nRF52 生产流程无外部 Flash，全部写片内。
- **地址**：用芯片 FICR 内出厂 `DEVICEADDR`（随机静态地址）作为 BLE 地址，**每台天然唯一，产线零操作**；私有 2.4G 的设备地址同源派生。不要自造"顺序 MAC"，易撞且被白名单机制反噬。
- **RF 校准**：nRF52 级芯片出厂已做射频参数 trim，**量产无需 RF 校准**（共识；这也是选 SoC 的隐性成本优势）。产测改为抽检：DTM 传导功率 + 灵敏度环回 + 天线装配后的 OTA 粗测（屏蔽箱 RSSI 阈值判 PASS/FAIL）。
- **绑定预置**：产线不预配对；首次用户配对即产线结束点。但要在出厂前验证配对流程（产测工位用标准主机模拟配对一次后清除绑定）。
- 老化与抽测：满载按键矩阵老化数小时 + 消费电流抽测（待机电流超阈值即筛），CR2032 接触不良类早期失效在此时拦截。

## 6. 售后高频问题速查（运营视角）

| 症状 | 常见根因 | 处置口径 |
|---|---|---|
| 偶发卡顿/丢字 | 2.4G 与 USB3/微波干扰；dongle 被金属机箱遮挡 | 换 USB 口/延长线（公知现象，见 [hardware/设计要点.md](hardware/设计要点.md) §1.4） |
| 电池显示还有电却断连 | CR2032 末期内阻上升，峰值电压跌落 | 换电池；低电量阈值按放电曲线实测调（不要按线性电压估算） |
| 完全连不上 | 绑定残留/白名单主机地址变了（主板维修换蓝牙） | 长按清绑定重配对 |
| 指示灯不同步（大小写灯） | 下行 Output 报告链路断 | 固件问题，走固件升级（Dongle 侧 USB 可升级，键盘侧经蓝牙 DFU 或收回） |
