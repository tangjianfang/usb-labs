## 1. 2.4G PCB 天线与匹配

### 1.1 天线形式

- **首选 PCB 倒 F / 曲折天线（IFA / MIFA）**：0 元件成本，量产一致性好；缺点是占地约 10×5mm 级别，且对净空区要求严格。
- 陶瓷贴片天线：占地小（3216 级），但要按厂商推荐地 nets（地平面尺寸）设计，否则频偏大；单价 0.1–0.5 美元量级。
- 弹簧/FPC 天线：结构受限时用，成本与装配工时上升。
- 键盘这种"大塑料壳 + 大地平面"的产品，PCB 天线放在板边、朝外壳天线窗即可。

### 1.2 π 型匹配网络（必留，不为省 3 个元件）

从 nRF52840 ANT 引脚到天线馈点，预留 **C-L-C π 网络**（串联臂电感 2.7–5.6nH、两并联臂电容 0.3–1.5pF 量级，0402）：

- 作用一：**工厂调匹配**。裸板 + 外壳状态下用网络分析仪（VNA）测回波损耗（目标 ≤ −10dB @ 2.44GHz），微调 π 网络后**固化进 BOM**，产线只抽测。
- 作用二：**吸收外壳频偏**。塑料外壳（尤其带颜色/电镀漆）通常把谐振点拉低数 MHz 到十几 MHz——π 网络是补救手段，装机状态下重新调过才算数。
- 串臂位置也可放 0Ω 电阻作为调试断点，便于把天线"切出去"单独测。

### 1.3 净空区（Keep-out）——新手第一大坑

- 天线正下方**所有层禁铜**（顶层、内层、底层全部挖空），包括地平面、走线、丝印电池标。
- 天线臂周围 ≥ 5mm 内尽量不走高速线；USB 差分线远离天线端。
- 天线区域板边不要放螺丝/金属弹片/电池（CR2032 是一大块金属！布局时电池离天线越远越好）。
- 地平面是天线的一部分：地越完整，谐振越接近设计值；键盘主板大，反而好做。

### 1.4 dongle 的天线特殊性

- dongle 插在机箱后面板时**整个天线被金属机箱罩住**，RSSI 显著下降——这是行业公知现象（社区共识，Nordic DevZone 上大量类似问题的结论都是"用延长线把 dongle 引出机箱"）。
- 商业做法：产品内附一根 USB 延长线/底座，说明书引导用户"插前面或用延长线"。
- 设计做法：dongle 天线放 PCB 短边端头，插上机箱后仍有部分露出。

## 2. 32.768kHz 晶振：精度 = 睡眠功耗

BLE 低功耗的本质是"睡到连接事件前一刻才醒来"。醒得准不准，取决于睡眠时钟：

| 睡眠时钟 | 精度 | 后果 |
|---|---|---|
| 外部 32.768kHz 晶振（±20ppm 量级） | 百万分之二十 | 从机提前极小窗口醒来即能对齐，睡眠电流可压到 µA 以下量级 |
| 内部 RC 振荡器（LFRC，百分比量级精度，以产品规格为准） | 比晶体差约 3 个数量级 | 漂移大 → 从机必须提前更早醒、监听更长的窗口 → 平均电流明显上升 |

设计要点：

1. **能上晶体就上晶体**，尤其键盘这种追求"月级续航"的产品。BOM 差价约 0.1–0.3 美元，换来的是续航宣传口径。
2. **负载电容按公式算，不要抄**：`CL = (C1·C2)/(C1+C2) + Cstray`，Cstray 取 2–5pF 估算；CL 不匹配 → 起振慢/频偏大，低温下尤其明显。
3. 布局：晶振紧贴芯片，走线短，包地；远离 DC/DC 电感与天线（开关噪声耦合进睡眠时钟 = 功耗与定时双双劣化）。
4. 软件侧配合：NCS 里选择外部晶体作为低频时钟源（devicetree/Kconfig），并确认校准策略——这一步漏掉时"上了晶体也白上"。
5. 32MHz 主晶振（HFXO）是射频与 USB 的时钟源，**不可省略**（nRF52840 无内部替代路径）；它是另一个独立的元件，别和 32.768k 混淆。

## 3. 电源：纽扣电池的峰值电流与去耦

- CR2032 容量约 210–240mAh，但**内阻随寿命显著上升**（全新几十 mΩ 级 → 寿命末期数十 Ω 量级），直接后果是末期高峰值电流时电压跌落、芯片复位——"电池还有电却频繁掉线"的售后假象。
- BLE 键盘的射频峰值电流只有 **mA 级**（nRF52840 0dBm 发射约 5mA 量级，DC/DC 开启；精确值查产品规格），CR2032 完全带得动——这正是 BLE 与 WiFi 方案的本质区别。
- 去耦策略：每个电源脚 100nF 贴脚；整板 4.7–10µF 储能电容扛发射突发（radio event）的电流阶跃；这个储能电容本质是给电池内阻"并联卸峰"。
- **开启 nRF 内部 DC/DC**（需外挂 10µH 电感 + 电容）：3V 纽扣电池场景下电流下降三成上下是社区共识量级，白赚续航，务必在软件里启用。
- SYSTEM OFF（掉 RAM 关机级睡眠，nA~µA 级）用于"深度关机/运输模式"；日常待机用 SYSTEM ON + 内存保持，唤醒即连。两者电流差 2–3 个数量级，营销页的"续航 X 月"按哪种模式算，要写进测试口径。
- 锂电方案（选项 B）：加充电 IC（线性充电即可，键盘充电电流不需要大）；升/降压后仍建议配合 nRF 内部 DC/DC 使用。

## 4. dongle 的 USB 部分

- nRF52840 内置**全速（Full-Speed，12Mbps）USB 设备控制器**，HID 中断端点 1ms 级轮询带宽绰绰有余；48MHz USB 时钟由 32MHz 晶振内部派生，**无需额外晶振**。
- VBUS 检测：电阻分压进 GPIO（dongle 是纯设备角色，不需要 PD/角色切换的复杂度）。
- ESD：D+/D-/VBUS 上放 USB ESD 阵列（USBLC6-2 类），**插拔件必加**；这是返修率统计里的低成本保险。
- 连接器两种做法：PCB 边缘金手指（最便宜，外壳即连接器护套）或立式 Type-A 插件（牢固）。金手指厚度/镀层按 USB 规范尺寸公差做，否则接触不良——[30-枝干-接口与供电/01-接口形态演进](https://github.com/tangjianfang/USBTree/blob/main/30-枝干-接口与供电/01-接口形态演进.md) 有连接器背景。
- USB 差分线 90Ω 差分阻抗、等长；全速信号对布线宽容度高，但仍不要跨分割、不要贴着天线走。

## 5. 布局检查清单（评审用）

- [ ] 天线净空区全层禁铜，天线窗在外壳对应位置开孔
- [ ] π 匹配网络元件位保留，串臂留 0Ω 断点
- [ ] 32.768k 晶振远离 DC/DC 电感、天线、USB 线
- [ ] 100nF 每脚 + 4.7~10µF 储能电容靠近 nRF VDD
- [ ] CR2032 座离天线 ≥ 20mm（金属体退避）
- [ ] dongle：VBUS 分压 + ESD + （可选）保险丝
- [ ] SWD 口（TagConnect 焊盘）引到量产夹具可达位置
- [ ] 按键（复位/配对/通道）人手可达位置，且不与天线区重叠
