# Lab5 经验实录：PD 供电的坑、成本与产品化

> 📍 [lab5-pd-charger/experience.md](./)
> 性质声明：本章内容为**公开资料的工程共识梳理**（规范条款 + 厂商应用笔记方向 + 拆解/测试社区的普遍结论），不转引任何具体文句；价格均为散量参考区间（以 2026 年前后渠道为准，随行情波动）。个人实测数据请自行记录并标注条件。

## 1. 协议兼容性实况：同为 PD，脾气各异

### 1.1 各家 Source 的 PDO 差异

拿着同一块诱骗板扫一圈办公室的充电器，你会得到一张很不均匀的表：

| 现象 | 普遍成因 | 对设计的影响 |
| --- | --- | --- |
| 多数 65W 头：5/9/12/15/20V 五档齐全 | 生态成熟档位组合 | 按档做策略即可 |
| 部分 30~45W 头没有 12V 或 20V 档 | 厂商按成本砍档 | Sink 策略必须能接受"次优档 + Capability Mismatch 置位" |
| 同标 65W，PPS 范围五花八门（3.3~11V/5A、3.3~21V/3A……） | PPS 是 APDO 自由声明 | 不要对 PPS 范围写死假设 |
| 手机私有快充（SCP/VOOC/FCP 类）不在标准 PDO 里 | 私有协议与 PD 并行，另走握手 | 标准能做的只有 PD 档位；别承诺"满速触发某手机快充" |
| 笔记本充电器对未知 Sink 保守（可锁定档位少） | Source 端 DPM 自保策略 | 用 Capability Mismatch 位 + 实测电流判断真实供给 |

**5 V/3 A（15 W）以上常要求 PD 认证**：USB-IF 认证本身非法律强制，但商用生态（大厂供应链、授权 logo、笔记本对"非认证源"限流的保守策略）实际把认证变成了 >15W 产品的普遍门槛。做产品前先查 [USB-IF 认证库](https://www.usb.org/compliance)，并确认客户/平台是否要求认证编号。

### 1.2 Sink 侧兼容性两条军规

1. 永远假设 Source 会突然重播 Source_Capabilities / 发 Hard Reset——Sink 状态机要能从任意状态恢复到 5V 安全态；
2. 不要只对自家充电器做测试就发货——至少覆盖：苹果/三星/小米/安克类大厂头、无名白牌头、充电宝、车充、拓展坞各一个。

## 2. 线缆的坑：假线与非标线

| 坑 | 表现 | 机理 |
| --- | --- | --- |
| 标"5A"无 E-marker 的线 | 100W 协商不上或只给 3A 档 | 规范要求 >60W/5A 线缆必有 E-marker；无芯片=按 3A 对待 |
| E-marker 造假/写错电流档 | 高功率下插头发热 | SOP' 读出的电流档与实际铜截面积不符 |
| 线阻过大（劣质长线） | PS_RDY 后设备端电压明显低于契约值 | 5A 下线阻压降数百 mV 量级；契约是 Source 端口的承诺，不含线损 |
| CC 异常的 legacy 转接线 | Sink 识别异常/只按 Default 档取电 | 非标 Rp 虚标或 CC 直通，见知识库 09 文"Legacy 与非合规适配器" |
| "240W 线"非 EPR 线 | EPR 进不去 | EPR 要求线缆经 SOP' 查询确认为 EPR capable |

开发用线建议：直接购买带认证标识的 **5A E-marker 线**（约 ¥20~60），并留一根作为"基准线"专测新板。

## 3. E-marker 成本账

| 项 | 参考区间（散量） |
| --- | --- |
| E-marker 芯片（单颗） | ¥0.3~1.5 |
| 5A E-marker 线（整线成品） | ¥20~60 |
| 普通 3A 线（对照） | ¥5~20 |

结论：**线缆是整机 BOM 里最容易被低估的可靠性变量**。充电头厂把"不配线/配认证线"写进规格，一半是成本、一半是把兼容性风险从自己身上摘出去。

## 4. SPR / EPR 产品定位

| 维度 | SPR（≤100W，20V/5A） | EPR（140/180/240W，28/36/48V/5A） |
| --- | --- | --- |
| 线缆 | 5A E-marker | 5A EPR-capable E-marker |
| MOSFET/TVS/采样 | 30~40V 档器件 | 60V+ 档器件，安规裕量重算 |
| 协议复杂度 | 标准 PDO/PPS | EPR 模式进入握手 + KeepAlive + 回落 |
| 典型产品 | 手机/平板/小笔记本充电器、拓展坞 | 游戏本、显示器、高功率坞站、多口桌面充电站 |
| 认证与整备成本 | 生态成熟 | 明显更高（器件、测试、线缆） |

建议：新产品与教学从 SPR 起步；EPR 是"已把 SPR 做稳"之后的第二阶段。

## 5. 安规与认证方向（做产品前必读）

| 区域 | 认证/标准 | 说明 |
| --- | --- | --- |
| 中国 | **CCC**（电源适配器类属强制目录）；安全标准方向 GB 4943.1-2022（对应 IEC 62368-1）；另有能效与 EMC 要求 | 无 CCC 不得出厂销售（目录内产品） |
| 欧盟 | CE：EN 62368-1（安全）+ EMC（EN 55032/55035 类）+ 能效 | 自我声明+技术文档 |
| 北美 | UL/ETL（UL 62368-1 方向）+ FCC EMC | NRTL 认证 |
| 生态 | USB-IF PD 认证（Logo 授权） | 非强制但商用普遍要求，见第 1 节 |

工程含义：IEC 62368-1（危害防护替代旧 60950/60065）是方向性框架，涉及初/次级隔离的爬电与电气间隙、材料耐热、单一故障条件等——**教学板不替代认证**，任何要接市电的电源都应交给有资质的实验室与认证工程师走流程。

## 6. 过压/过流保护设计与返修案例思路

### 6.1 保护设计清单（Sink 与 Source 通用）

| 保护 | 实现通道 | 设计要点 |
| --- | --- | --- |
| OVP 过压 | 硬件比较器直关 MOSFET（毫秒级内）+ 软件轮询辅助 | 阈值=契约电压+裕量；分压电阻精度直接影响判定 |
| OCP 过流 | 检流电阻+比较器（硬件），I2C 电流监控（软件） | 双通道：硬件管"断得快"，软件管"报得准" |
| 短路 | MOSFET 限流/关断 + Source 端协议层撤电 | 关断速度与 MOSFET 安全工作区相关 |
| 过温 | NTC 贴 MOSFET/变压器/协议芯片 | 多级：降额→停机；恢复要带回差 |
| 反灌/倒流 | 背靠背 MOSFET 阻断 | 无电池的 Sink 也建议做（防多源对插） |

### 6.2 返修案例分析框架（思路模板，非具体案例）

| 现象 | 常见根因方向 | 设计对策 |
| --- | --- | --- |
| 插上就烧 VBUS MOSFET | 栅极驱动过压/振铃；OVP 反应太慢；热插拔浪涌 | 栅极串阻+钳位、比较器直关、输入浪涌抑制 |
| 用一段时间后协商不稳 | CC ESD 器件失效/腐蚀；连接器磨损 | ESD 器件选型与位置复查；连接器寿命规格 |
| 输出电压漂移/带载跌 | 采样分压漂移；检流开尔文未接好；反馈环路补偿 | 精度预算重算；四线制检查 |
| 充电器识别但功率上不去 | E-marker 线缆非 5A；VCONN 未供；DPM 保守策略 | 分辨"线的问题"与"板的问题"再动手 |
| 复测不良集中某批次 | 器件来料（协议芯片批号）、焊接（MOSFET 虚焊） | 建立批号追溯表 |

返修流程建议：**现象 → 复现条件 → 关键点电压（CC/VBUS/INT）→ 分层定位（线/板/协议/电源）→ 根因 → 设计变更单**。每一步留记录，让第 N 次返修为第 N+1 次设计供弹药。
