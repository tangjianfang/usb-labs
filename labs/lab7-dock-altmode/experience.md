## 1. 兼容性名单是核心竞争力，不是营销点缀

- 扩展坞的所有复杂度都花在与**别人家 PC** 的相处上：不同品牌/世代的笔记本，PD 固件、USB4 CM、DP Alt Mode 实现各有差异。同一颗方案芯片，换个笔记本组合就可能"4K60 变 4K30""网卡消失"。
- 行业共识做法：厂商维护**官方兼容列表**（机型 × 系统版本 × 坞站固件版本三维矩阵），新机型发布即补测；大厂（Dell/Anker/CalDigit 类）的差异化很大程度就在这份矩阵的厚度和固件跟进速度。
- 对开发者的启示：选购坞站先查兼容列表；自研坞站，兼容性测试（每机型插拔/显示/网卡/充电四件套）要排进 DVT，人力预算按"数十台主流机型"规划。

## 2. 发热与降速：差评第一来源

- 结构：USB4 主控 + 显示转换 + 2.5G 网卡 + PD 直通全部挤在掌心大的铝壳里，持续满载（拷盘 + 双 4K + 充电）时壳体温度轻松到烫手区间。
- 连锁反应：热量 → 主控/网卡热降频 → "拷大文件几分钟就掉速""网卡从 2.5G 掉到几百兆"——这是评测与电商评论区最常见的负反馈模式（公开共识，非引言）。
- 应对（设计侧）：铝壳一体化导热 + 导热垫压芯片、功率预算留余量（不是适配器给多少就承诺多少）、固件限温策略透明化。
- 应对（产品侧）：规格表写"持续吞吐"而不是"峰值吞吐"；说明书写明"充电直通功率随负载动态分配"。把物理规律写进预期管理，是唯一可持续的方案。

## 3. 认证成本量级

| 认证 | 内容 | 费用量级（概要，随项目/机构浮动） |
|---|---|---|
| USB-IF 合规 | Type-C/PD/Hub/Billboard 一揽子测试，过审上 Integrator's List，可用 USB 商标 | 单项目数万元人民币起，复测另计；USB4 项目更高 |
| 雷电（Thunderbolt）认证 | Intel 授权链 + 测试 + 版税 | 授权与测试费用 + 每台版税，量级需与 Intel 渠道确认 |
| 各国 EMC/安全 | CE/FCC/CCC 等 | 与一般电子产品同量级 |

- 结论级判断：**认证把小厂挡在 USB4/雷电品类之外**——这也是为什么低价坞站普遍走"DP Alt Mode + USB3"而非 USB4 路线，不是技术不会，是账算不过来。
- 测试可委托 USB-IF 授权实验室（如 GRL、Allion 等授权实验室，公开信息见各自官网 https://www.graniteriverlabs.com/ 、https://www.allion.com/ ）。

## 4. 返修率大户 = 线缆（以及插拔件）

- 扩展坞售后工单里，相当比例最终定位是**线缆**而不是坞站：杂牌无 E-marker 线只能跑 3A/60W 与 USB2.0、劣质线接触电阻大、反复插拔后微裂——症状全指向"时好时坏"（公开资料共识）。
- 系统性对策：
  - 随坞附赠**认证过的全功能线缆**（BOM +5–10 美元量级，换回口碑）；
  - 固件 + Billboard 把"线缆能力不足"翻译成人话提示用户；
  - 包装与详情页教育用户认准线缆等级标识（3A/5A、40Gbps、240W 等标）。
- 插拔件同理：Type-C 座的插拔寿命（规格 1 万次量级）是坞站寿命短板，结构上做"线缆承重释放"（理线槽）能显著降低座子脱焊类返修。

## 5. 其他实况速记

- **固件可升级是标配**：PD 控制器/主控固件 OTA（经 USB 升级工具）是兼容性问题的唯一长期解，售后期固件迭代能力决定产品生命长度。
- **双显示器是分水岭**：单 4K60 谁都行；双 4K60 就进入 MST/DSC/带宽分配的技术深水区，差价与差评都集中在这里。
- **macOS 差异**：Apple 平台不支持 MST 扩展模式（多屏各占一路），同等硬件在 macOS 上双屏能力弱于 Windows——产品规格必须分平台标注，这是电商客服的日常考题（公开共识）。
- **定价锚点**：非 USB4 百元级人民币，USB4/TB 数百到千元级人民币；认证与授权成本决定底价，兼容矩阵决定溢价。
