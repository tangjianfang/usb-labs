# 主机侧：UVC 预览调参 与 UAC 录音（Linux / Windows）

> 前提：设备已按 [../firmware/README.md](../firmware/README.md) 枚举成功（或用任意现成 UVC 摄像头 + UAC 麦克风）。
> 所有 UVC 调参最终都落到 UVC 类请求上——文末"控件↔实体对照表"告诉你每条命令对应描述符里的哪个实体。

---

## 1. Linux 视频侧（uvcvideo + v4l2-ctl）

### 1.1 找设备、看能力

```bash
# 设备识别：uvcvideo 驱动加载即说明 UVC 描述符被吃下了
dmesg | grep -i uvc          # "uvcvideo: Found UVC ... device"
v4l2-ctl --list-devices      # UVC 设备通常注册 /dev/video0（+ metadata 节点 /dev/video1）

# 能力清单 = VS 格式/帧描述符的直接翻译（与固件源码逐项对照）
v4l2-ctl -d /dev/video0 --list-formats-ext
#   MJPG 1280x720 30fps / 640x480 30fps ←→ firmware/src/uvc_descriptors.c 的帧描述符

v4l2-ctl -d /dev/video0 --all        # 当前格式/帧率/全部控件快照
lsusb -v -d 1234:5678 | less         # 反读全部描述符（学习首选姿势）
```

### 1.2 设分辨率 / 格式 / 帧率

```bash
# 设格式与分辨率（对应 PROBE/COMMIT 里的 bFormatIndex/bFrameIndex）
v4l2-ctl -d /dev/video0 --set-fmt-video=width=1280,height=720,pixelformat=MJPG
v4l2-ctl -d /dev/video0 --set-parm=30          # 帧率 → dwFrameInterval=333333

# 快速验流（不动 ffmpeg 就能确认在吐帧 + 实测帧率）
v4l2-ctl -d /dev/video0 --stream-mmap --stream-count=90 --stream-to=/dev/null
```

### 1.3 曝光/白平衡等控件（打到 VC 实体）

```bash
v4l2-ctl -d /dev/video0 --list-ctrls-menus     # 枚举全部控件与可调范围
# 自动曝光模式（Camera Terminal CS=0x02）：1=手动 3=光圈优先(自动)
v4l2-ctl -d /dev/video0 --set-ctrl=auto_exposure=1
v4l2-ctl -d /dev/video0 --set-ctrl=exposure_time_absolute=157   # 手动绝对曝光 CT CS=0x04
v4l2-ctl -d /dev/video0 --set-ctrl=white_balance_temperature=4600   # PU CS=0x0A
v4l2-ctl -d /dev/video0 --set-ctrl=brightness=10                    # PU CS=0x02
v4l2-ctl -d /dev/video0 --set-ctrl=power_line_frequency=1           # 抗闪烁: 1=50Hz（"日光灯条纹"就调它）
```

> 注意：很多 UVC 相机在自动曝光开启时拒绝手改 `exposure_time_absolute`——先切 `auto_exposure=1`（手动），对应 GET_INFO 能力位。

### 1.4 ffmpeg 录制

```bash
# 录制：MJPEG 直拷（零转码，文件即 sensor 原始压缩流）
ffmpeg -f v4l2 -video_size 1280x720 -framerate 30 -i /dev/video0 -c:v copy out.mkv

# 或转 H.264 存档（采集棒/会议录像常用管线）
ffmpeg -f v4l2 -video_size 1280x720 -framerate 30 -input_format mjpeg -i /dev/video0 \
       -c:v libx264 -preset veryfast -crf 23 out.mp4

# 边录边看实时帧率/丢帧（stderr 的 fps 与 drop 统计是调参关键指标）
ffmpeg -f v4l2 -i /dev/video0 -c:v copy -f null - 2>&1 | grep -E "fps|drop"
```

### 1.5 Linux 音频侧（UAC1 → ALSA）

```bash
arecord -l                     # 列出录音设备：card N: UVC-UAC-Lab4
alsamixer -c N                 # F6 选卡 → MUTE/VOLUME 就是 FU2 类请求（拖滑条=SET_CUR）

# 录 10 秒 48k/16bit 单声道（与固件描述符的 tSamFreq 对照）
arecord -D hw:N,0 -f S16_LE -r 48000 -c 1 -d 10 test.wav
aplay test.wav                 # 回放验证（无杂音/无周期性咔哒）

# 查时钟漂移：录满 1 小时对比文件时长，偏差 ppm 即真实时钟精度（见 experience.md §4）
arecord -D hw:N,0 -f S16_LE -r 48000 -c 1 -d 3600 long.wav -v
```

**Audacity（图形化）**：Edit → Preferences → Recording → Device 选对应卡与通道 → 录音轨。它能直观显示削波（音量滑条打到 0dB 附近时观察 FU 增益效果）。

## 2. Windows 侧

### 2.1 相机应用与隐私设置

- 内置 UVC 驱动（Usbvideo.sys）即插即用：UVC 1.1 从 Win7 起、UVC 1.5（含 H.264）从 Win8 起（能力矩阵见 Microsoft Learn 链接于文末）；
- **"相机"应用**直接预览；OBS / Teams / Zoom 在设备列表里挑选（名字来自 iProduct 字符串）；
- **隐私开关是第一大坑**：设置 → 隐私和安全性 → 相机 → "相机访问"与"允许应用访问相机"必须开；关掉时 UVC 流会被系统直接停掉（表现：应用黑屏但 `lsusb` 类工具仍见设备）。详聊见 [../experience.md §3](../experience.md)。

### 2.2 ffmpeg（dshow 后端）

```powershell
# 列出设备名（名字带引号原样拷给 -i）
ffmpeg -list_devices true -f dshow -i dummy

# 录制 MJPEG
ffmpeg -f dshow -vcodec mjpeg -video_size 1280x720 -framerate 30 ^
       -i video="USB-Labs UVC Camera" -c:v copy out.mkv
```

调参工具：相机应用 → 设置齿轮（曝光/白平衡/抗闪烁，映射同一批 UVC 控件）；进阶用 OBS 的"摄像头属性 → 配置视频"或 AMCap。

## 3. 控件 ↔ UVC 实体对照表（调参时心里有协议）

| v4l2 控件 | UVC 位置 | CS（选择子） | 总线动作 |
|---|---|---|---|
| auto_exposure | Camera Terminal (ID=1) | 0x02 | SET_CUR/GET_CUR，bmRequestType=0x21/0xA1，wValue=0x0200，wIndex=0x0100 |
| exposure_time_absolute | Camera Terminal | 0x04 | 同上寻址；范围来自 GET_MIN/GET_MAX |
| brightness | Processing Unit (ID=2) | 0x02 | wIndex=0x0200 |
| white_balance_temperature | Processing Unit | 0x0A | PU 下常见 2800–6500K |
| power_line_frequency | Processing Unit | 0x05 | 0=禁用 1=50Hz 2=60Hz |
| gain | Processing Unit | 0x04 | 模拟增益档位 |

完整 CS 编码表：知识库 [UVC 规范级-控制与格式全表](https://github.com/tangjianfang/USBTree/blob/main/20-枝干-设备类协议/Video-UVC/01-UVC规范级-控制与格式全表.md)。

## 4. 常见问题速查

| 现象 | 先查 | 次查 |
|---|---|---|
| `--list-formats-ext` 为空 | dmesg 里 uvcvideo 是否报描述符解析错误 | `lsusb -v` 对照固件描述符 wTotalLength |
| 帧率不足（协商 30 实测 15） | `--stream-mmap` 实测；换直插主机口 | Hub 带宽挤占（[../experience.md §2](../experience.md)）；画质参数 |
| Linux 下设备 busy | cheese/guvcview 是否占用中 | `fuser /dev/video0` |
| Windows 黑屏 | 隐私设置（§2.1） | 相机被独占模式占用 |
| 录音无声 | alsamixer 里 MUTE | 采样率/通道与描述符是否一致（arecord -v） |
| 录音漂移/断续 | 长录测漂移（§1.5） | 时钟声明与实现不符（[../experience.md §4](../experience.md)） |
