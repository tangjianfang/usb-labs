# Lab1 硬件设计要点（量产视角）

对应 BOM 见 [BOM.csv](BOM.csv)。基准平台 RP2040 的权威依据是官方《Hardware Design with RP2040》
（https://datasheets.raspberrypi.com/rp2040/hardware-design-with-rp2040.pdf ）与 RP2040 Datasheet，
本文与官方文档冲突时**以官方文档为准**。USB 物理层概念见知识库
[03-物理层与电气特性](https://github.com/tangjianfang/USBTree/blob/main/10-树干-USB核心/03-物理层与电气特性.md)。

## 1. USB 差分对（D+/D-）

- **阻抗**：90Ω 差分阻抗（USB 2.0 线缆与板级差分对的目标值）。2 层板通过线宽/间距与参考平面距离实现，
  下单时向板厂提供阻抗控制要求，让其给出线宽参数并出阻抗报告。
- **等长**：FS-only 产品要求宽松，但建议按 <5mil（0.127mm）的配对等长布线，让同一布局可直接复用给 HS 复用（如后续换 RP2350/USB HS 桥）。
- **参考地**：全程有完整的 GND 参考平面，**禁止跨分割**；换层时伴随地过孔。
- **避让**：远离晶振（Y1）、所有时钟走线、LDO 开关节点（本设计 LDO 为线性，无此问题）。
- **过孔最少**：D+/D- 从 ESD 器件到 MCU 尽量不打过孔；共模电感（CM1，可选）串在 ESD 与 MCU 之间。
- **串联电阻**：RP2040 官方 Pico 原理图未放 USB 串联电阻，是否需要以 RP2040 硬件设计指南为准。

## 2. ESD 与连接器

- **位置**：ESD 阵列（U4，USBLC6-2SC6 类）必须**紧贴连接器信号引脚**（几 mm 内），先于共模电感与 MCU；
  放在 MCU 附近等于没保护——放电通路必须最先遇到 ESD 器件，而不是先绕过板子再回来。
- **地回流**：ESD 器件的地过孔就近、多打孔；连接器金属外壳接地处理（直接接地或经 RC/磁珠接地属于 EMI 整改手段，二选一后固定下来）。
- **认证对应**：CE（EN 55032/EN 61000-4-2 等类目）与 FCC Part 15B 对接口浪涌/静电的实测是常见失败点，见知识库
  [03-USB-IF合规认证](https://github.com/tangjianfang/USBTree/blob/main/70-枝干-调试测试与安全/03-USB-IF合规认证.md)。
- **连接器质量**：Type-C 母座是整板接触失效概率最高的器件。务必走授权渠道；低价座子常见问题：
  端子镀层偷薄（插拔数百次后接触阻抗飙升）、弹片回弹力不足、耐温差导致回流焊后变形。
  插拔寿命要求：Type-C 为 10000 次量级（以 USB 连接器规范与厂商规格书为准）。

## 3. 晶振布局（Y1）

- **负载电容计算**：CL1 = CL2 = 2 × (CL − Cstray)。以 CL=10pF、Cstray≈2~3pF 估算 → 14~16pF，BOM 取 15pF 为初值；
  最终以晶振厂商的频率偏差测试（或官方指南默认值）为准。
- **走线**：晶振到 XIN/XOUT 尽量短（<3mm 量级）、对称，负载电容地脚就近回地；晶振下方保持完整地平面，
  与 USB 差分对、板边保持距离。
- **不要目测留大环**：晶振环路面积大 = 对外辐射 + 对内易受扰，USB 误码会表现为"偶发掉键/卡顿"这类极难排查的问题。

## 4. 电源与 VBUS

- **路径**：VBUS(5V) → C13(10μF)+100nF → U3 LDO → 3.3V（MCU 与外设）；LDO 输出就近放 C14。
- **去耦**：RP2040 每个电源引脚一个 100nF（位号以官方 Pico 原理图为准），IO 供电 3.3V 与内部核 LDO 输出按 Datasheet 处理。
- **浪涌与并联电容（诚实声明）**：网上流传"USB 设备并 500μF"的说法**不是规范原文的直接数值**。
  USB 2.0 规范 §7.2.4 对挂起电流、1~100ms 浪涌电流限值以及无限流时允许的并联电容条件有明确规定；
  工程实践是：小容量去耦 + LDO 自身软启动特性即可满足本设计（100mA 级 bus-powered）。
  如需大容量储能，必须配限流/软启动电路。**具体限值与条件以 USB 2.0 规范 §7.2.4 为准。**
- **bMaxPower 一致性**：本固件描述符宣告 100mA（`usb_descriptors.c` 中 `bMaxPower=50`，单位 2mA）。
  硬件实测整机工作电流必须留余量低于宣告值——超电流会被集线器端口断电，是售后"随机掉线"的典型根因。

## 5. RP2040 最小系统

- **Flash（U2）**：QSPI 接 W25Q16 类；布局尽量靠近 RP2040，四条数据线等长尽力而为（FS 时钟下要求不苛刻）。
- **BOOTSEL（SW1）**：按键接 QSPI_SS 网络（按下拉低），复位时由 ROM 采样进入 USB 大容量存储烧录模式，
  对应"拖 uf2 文件"的量产友好处，见 `firmware/README.md`。具体电路以 RP2040 Datasheet §2 与 Pico 官方原理图为准。
- **VREG**：RP2040 内部核 LDO 的设置引脚按 Datasheet 固定接法处理，不可悬空。
- **GPIO 上拉**：演示按键 SW2~SW4 使用 MCU 内部上拉（软件 `gpio_pull_up`），按下接地——省 3 颗外部电阻（成本导向决策）。

## 6. 结构与连接器固定（DFM/DFA）

- **外壳开孔**：Type-C 开孔对位公差 ±0.1mm 量级；连接器端面距外壳内壁留插头介入空间（公头护套深度），
  避免插拔应力全部落在 SMT 焊点上。
- **固定**：连接器优先选带定位柱/带固定焊耳（SMT+插脚复合）的型号；纯 SMT 卧贴座在产线插拔测试中易脱焊。
- **按键手感**：薄膜/锅仔片方案按目标力度（公开资料常见 160~300gf 量级）选型，寿命指标写进来料检验标准。
- **LED 光导**：外壳指示灯建议光导柱，避免开大孔漏光影响观感（外观成本也是商业成本）。
