# Lab2 硬件设计要点（STM32F103C8T6 参考平台）

> 配套：[BOM.csv](BOM.csv) ｜ 概念背景：知识库 [CDC-通信设备类](https://github.com/tangjianfang/USBTree/blob/main/20-枝干-设备类协议/CDC-通信设备类/)
> 本文按"工业现场 24V 供电 + USB 调试口 + RS485 共存"的典型工业小设备形态展开。

## 1. USB D+/D- 与 1.5kΩ 上拉（F103 的头号陷阱）

### 1.1 事实核查：F103 没有内置上拉

USB 2.0 全速设备规范要求：**D+ 必须通过 1.5kΩ（±5%）电阻上拉到 3.0~3.6V**，主机据此识别全速设备。逐型号核实（依据 ST 官方 [AN4879](https://www.st.com/resource/en/application_note/an4879-introduction-to-usb-hardware-and-pcb-guidelines-using-stm32-mcus-stmicroelectronics.pdf) 与 [RM0008](https://www.st.com/resource/en/reference_manual/rm0008-stm32f101xx-stm32f102xx-stm32f103xx-stm32f105xx-and-stm32f107xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)）：

| 型号 | D+ 1.5kΩ 上拉 | 处理方式 |
|---|---|---|
| **STM32F103**（本 Lab） | **无内置，必须外接 1.5kΩ 到 3.3V** | BOM 中 R10 |
| STM32F105/F107（Connectivity Line） | 有内置，软件可控 | 不需要外接 |
| STM32F0/F3/L4/F4 等较新系列 | 有内置（BCD/断开控制寄存器） | 不需要外接 |
| CH32V203 | 内置且软件可控 | 不需要外接 |

结论：**F103 的 BOM 里 1.5kΩ 1% 电阻不是可选项**。上拉必须接 3.3V——AN4879 明确警告不要拉到 5V。

### 1.2 蓝pill（Blue Pill）的 R10 教训

市售蓝pill 开发板的 USB D+ 上拉电阻 R10 长期被错装成 **4.7kΩ 甚至 10kΩ**（社区公开资料共识，如 [ overcome wrong pullup 实测记录](http://amitesh-singh.github.io/stm32/2017/05/27/Overcoming-wrong-pullup-in-blue-pill.html)）。上拉偏弱时：

- 对多数"宽容"的主机能枚举成功，但对部分主板 USB 口、带线长或 hub 的环境会**间歇性枚举失败/无法识别**；
- 表现为"同一块板，A 电脑好好的，B 电脑死活认不出"——这是硬件返修与客户投诉的经典来源。

给 Lab 的操作建议：拿到蓝pill 先量 R10，非 1.5kΩ（1.5~1.8kΩ 均可接受）直接更换。自己画板则严格 1.5kΩ 1%。

### 1.3 软连接（Soft-Connect）电路：改 PID/枚举测试必备

F103 无法软件断开内置上拉（它本来就没有），想在不拔线的情况下让主机"重新枚举"（例如 DFU 升级后换身份重连、测试描述符改动），需要软连接电路——ST 官方评估板的通行做法：

```
3.3V ──[R10 1.5kΩ]──┬──────> PA12 (USB D+)
                    │
                  [Q1 NPN/P-MOS 开关]
                    │
PB15(示例 GPIO) ────┘   固件：默认拉低断开上拉 → 配置好 USB 后再接通
```

细节（元件选型、限流电阻取值）**以 ST 评估板参考设计为准**（可在 [ST 官网](https://www.st.com/en/microcontrollers-microprocessors/stm32f103c8.html) 的 CAD Resources 下载对应原理图）。不焊接此电路也能完成本 Lab——重新枚举退化为"USB 复位 + 必要时拔插一次"。

### 1.4 USB 差分对布线

- D+/D- 平行等长差分走线，目标差分阻抗 **90Ω**（2 层板需向板厂备注阻抗工艺，见 BOM PCB 行）；
- 22Ω 串阻（R11/R12）靠近 MCU 端，USBLC6 防护器件**靠近连接器**——器件位置放反是常见错误；
- 差分对下方保持完整地平面，禁止跨分割；远离晶振、RS485、24V 功率回路，平行间距 ≥3 倍线宽；
- VBUS 在连接器处就近放 10uF + 0.1uF，并串 500mA 自恢复保险丝（F1）。

## 2. ESD 与浪涌防护链

工业现场 USB 口是头号静电入口（人员插拔、干燥环境）。防护分两级：

| 位置 | 器件 | 防什么 | 要点 |
|---|---|---|---|
| USB D+/D-/VBUS | USBLC6-2SC6（或 PESD1CAN 类，结电容 <1pF） | 人体放电 ±15kV 级 | 结电容大了会损伤 USB 眼图，**不能用普通大电容 TVS 替代** |
| 24V 输入端子 | SMBJ33CA + 防反接（SS34/PMOS）+ PTC | 浪涌/反接 | 柜内感性负载反冲是 24V 口的日常 |

防护地策略：ESD 电流需要低阻抗回流路径，USB 连接器外壳接地脚处理（接地还是悬空、经 RC 还是磁珠接地）**以整机 EMC 测试结果为准**，无测试条件时参考同类量产工业设备的通行做法（外壳金属件接地）。

被静电打坏的板子怎么分析，见 [../experience.md](../experience.md) 第 5 节"ESD 击穿返回件分析思路"。

## 3. 工业输入电源：24V → 5V → 3.3V

```
24V端子 ──PTC── 防反接(PMOS) ──SMBJ33CA──┬── MP1584EN Buck → 5V ──┬── AMS1117-3.3 → 3.3V
                                        └─ 22uF/50V              └─ 22uF+0.1uF
```

- **两级方案的性价比**：Buck 落 5V（同时供 USB VBUS 侧逻辑与 RS485 上拉），再 LDO 落 3.3V 给 MCU。24V 直接落 3.3V 的单级高压 Buck（如 LMR51430/TPS54331）效率更高，二选一皆可；
- MP1584EN 输入上限 28V，对"24V 标称"的柜内电源裕量偏紧——工业 24V 实际可能漂到 26~28V，**量产设计建议选 36V/42V 耐压的 Buck**，Lab 阶段 MP1584 够用；
- 3.3V 给 VDDA 单独经磁珠滤波（MCU 内 PLL/USB 收发器对 VDDA 噪声敏感）；
- 晶振 Y1 必须用 **8MHz 外部晶振**：F103 的 USB 48MHz 时钟由 HSE 8MHz×9=72MHz 再 1.5 分频得到，用内部 HSI 跑 USB 属于超规格使用，枚举成功率随温度漂移（RM0008 对 USB 时钟源有明确要求）。

## 4. 与 RS485 的共存布局（工业设备常态）

CDC 调试口设备常同时挂着 RS485 总线，布局冲突点：

1. **隔离 vs 非隔离**：本 Lab 基础版选非隔离 SP3485/MAX3485（BOM 可选项）。量产进柜设备**公开资料共识是推荐隔离方案**——数字隔离器（Si8621/ADuM1201 类）+ 隔离 DC-DC（B0505S-1W 类），防止现场共模电压差打坏端口。隔离器件具体选型以你的耐压等级需求与参考设计为准；
2. **空间分区**：USB 差分对（敏感、90Ω）与 24V/RS485（嘈杂）分居板两侧，中间留给 MCU；端子一律放板边；
3. **地策略**：非隔离设计单点共地，RS485 端子处不另设"数字地/现场地"分叉；120Ω 端接与失效保护偏置电阻按现场拓扑留焊位（装/不装由跳线决定）；
4. **线缆**：RS485 用双绞屏蔽线，屏蔽层单端接机壳。

## 5. SWD 与 BOOT0：救砖通道必须保留

- **CN3 SWD 排针（3V3/SWDIO/SWCLK/GND）**：首次烧 bootloader、RDP 加密后的返修、DFU bootloader 自身变砖的救援，全靠它。量产板哪怕没有排针，也要留 2x2 测试焊盘；
- **J1 BOOT0 跳线**：短接到 3.3V 复位即进 ST ROM 系统 bootloader（USB DFU，VID 0x0483/PID 0xDF11）——这是"固件升级代码本身写坏了"时的最后底牌，架构讨论见 [../firmware/src/bootloader选型与跳转设计.md](../firmware/src/bootloader选型与跳转设计.md)；
- SWD 走线远离 USB 差分对与 24V 回路，排针信号上可预留 22~100Ω 串阻焊位抑制引线天线效应。

## 6. 结构与连接器

- Type-B 母座带面板固定孔（工业机柜常见），USB-C 需注意 CC 下拉电阻配置（本设备是 Device，按 UFP 处理）；
- USB 口是插拔应力集中点，板内连接器焊盘按规范补强（拖锡脚/通孔固定脚），外壳开孔与连接器对位公差要留。

## 7. 焊接后上电检查清单

- [ ] 不插 USB，量 D+ 静态电压 ≈ 0V（未连接时）；插入后 D+ ≈ 3.3V（经 R10 上拉）
- [ ] 3.3V/1.8V(VDDA2 域如有) 电源纹波 <50mV
- [ ] 8MHz 晶振起振（示波器看 OSC_OUT 正弦，或直接看枚举结果）
- [ ] SWD 能识别芯片、读出 UID（UID 还要用作 USB 序列号，见 usb_descriptors.c）
- [ ] J1 跳到 BOOT0=1 复位，Windows/Linux 能出现 `STM32 DFU` 设备（VID 0x0483/PID 0xDF11）
- [ ] ESD 枪/异味检查：任何器件发热异常立即断电排查焊接短路
